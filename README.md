# Recipe Catalog

A personal recipe cataloging system with iterative note-taking capabilities.

## Features

- Catalog your favorite recipes
- Add notes and iterations to recipes
- Search and filter recipes
- Rate your recipes
- Dark theme UI similar to Codes

## Development

1. Clone the repository
2. Install dependencies: `npm install`
3. Start the development server: `npm start`
4. Open your browser to http://localhost:3000

## Project Structure

- `/public` - Static HTML, CSS, and JavaScript files
- `server.js` - Express server for serving static files
- `railway.json` - Railway deployment configuration

## Technologies

- Express.js for serving static files
- Vanilla JavaScript with localStorage for data persistence
- CSS with a dark theme similar to Codes

## Deployment

This application is configured for deployment on Railway with automatic builds.
